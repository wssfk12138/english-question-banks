# 英语刷题机题库

本仓库独立分发英语刷题机 ESQ 题库。题库文件存放在 Releases；Git 仅保存目录清单、校验值和发布说明。

## 导入目录

固定目录地址：https://raw.githubusercontent.com/wssfk12138/english-question-banks/main/question-bank-catalog.json

在英语刷题机的远程题库目录中填写该地址，刷新后选择题库下载并按提示导入。目录更新不会自动覆盖应用中的题库或做题记录。

## 兼容旧入口

原应用仓库的 question-banks-v1.2.0 Release 中保留 question-bank-catalog.json，并将下载地址指向此仓库。已配置该目录的客户端可继续刷新；原四个 ESQ 附件在迁移校验完成后删除。旧版客户端针对旧仓库设置的备用下载线路不会自动适用于新仓库。

沿用各包原有 NOASSERTION 声明，不为原始试题新增授权；具体声明见 ESQ 内 manifest.json。本仓库不包含原始 PDF/Word、应用数据库、学习记录或私有校对材料。
